# Blox Fruits Interest Discord Bot

Python Discord bot for `/interest <fruit>` using your existing API.

API base: https://bloxfruitinterest.onrender.com

## Setup

1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`.
4. Copy `.env.example` to `.env`.
5. Put your Discord bot token in `.env`.
6. Invite the bot with the `bot` and `applications.commands` scopes.
7. Run `python bot.py` or double-click `start.bat`.

## Commands

`/interest <fruit>` — gets fruit, value, demand, trend, and interest from the API.

`/api` — checks whether the API is reachable.

Never share your Discord bot token or upload `.env` publicly.
